# 使用说明

## 连接与登录

登录页“连接服务”保存主机局域网地址，模拟器访问本机通常为 http://10.0.2.2:8000。服务端 /health 应显示 auth_required=true、data_schema=3。模型未就绪可登录和管理业务，不能开始识别。

客户端 1.2.0 开始训练前检查 `local_skeleton_v1` 能力；旧服务会提示升级，需配套更新服务端。

默认患者账号密码登录，下方管理员入口登录工作人员；初始工作人员账号 admin / 123。工作人员创建档案，核对患侧和前臂长度后分配患者账号。账号为 3–32 位字母、数字、下划线、点或短横线，统一小写且唯一；密码为 8–128 字符，已有账号留空可保留原密码，不能查看原密码。账号修改会撤销旧登录，训练中不能修改。

患者可不绑定邮箱；邮箱用于验证码登录和密码找回，由工作人员绑定且全局唯一。找回时输入账号、绑定邮箱、验证码和两次新密码。验证码五分钟有效、六十秒发送间隔、最多五次尝试且单次使用；找回和登录验证码独立。无邮箱或无法收信联系工作人员，工作人员账号不走患者找回。SMTP 需在后端配置，无固定验证码入口。

患者仅访问本人资料、计划和记录，不能修改档案、计划或教学审核。令牌本地使用系统 Keystore 加密，患者二十四小时、工作人员八小时。退出、到期或切换服务后重新登录。

## 计划与训练

工作人员设置 1–6 个不重复动作及目标次数、顺序、每周训练日和生效日期。首次计划可当天生效，已有计划调整最早次日生效；唯一待生效版本可替换，历史版本保留。患者单项练习仅允许当前计划内动作与目标，六动作教学均可观看。

计划/单项 → 整次前测 → 入镜准备 → 倒计时 → 训练/项间休息 → 整次后测 → 汇总。准备阶段仅本地预览，不提前计数；训练默认显示“骨架画面”，在本地视频上绘制服务端返回的人体与手部关键点。“本地画面／骨架画面”切换只控制骨架显示，不重连、不清零、不停止识别。连续 300 ms 无可用骨架即隐藏，恢复后重新显示。达到目标只提醒，需手动结束。训练横屏，其他页面支持横竖屏；编辑档案和计划时固定方向保护表单。

采集继续请求 640×480、15 FPS，实际出帧率由设备决定。本地视频不等待识别结果，快速动作时骨架可能短暂落后；网络 RTT 不等于完整画面延迟。

疼痛/疲劳 0–10 分，默认未填；零分、未填和跳过分开保存。后测增加困难程度，不适说明可选填。实际开始后不能改前测，动作之间不重复问卷。

“因不适结束”保存部分结果、结束整次训练并提供可跳过后测，不计作计划完成。切后台、断线和令牌失效按不同原因中断，不续接旧计数。结果先保存在服务端，丢失响应按会话 ID 查询；后测失败可稍后补填，不覆盖训练结果。

## 工作人员远端诊断

工作人员登录后，在“设置 → 设备与服务”开启“下一次训练开启远端诊断”。成功建立下一次训练连接后开关自动复位；退出登录或切换服务也会清除。患者不能开启诊断。

该次训练可通过独立诊断入口查看服务端收到并解码后的画面，不带服务端骨架标注；“本地／骨架”切换仍可使用。远端画面经过回传压缩，检查上传质量时可按需获取当前会话的一张无损 PNG。抓帧只保存在内存，不在服务端落盘。诊断结束后，下次训练恢复日常模式；训练途中不能新增诊断视频轨。

诊断参数中的“解码→绘制”为服务端解码出帧到 Android 骨架绘制的估计耗时，不包括采集和上传，时钟校准不可用时标为不可用。完整画面延迟需要外部拍摄测量。

## 日程与记录

按北京时间计算计划日；应训练日全部动作正常结束记一天完成，目标是否达到另列。同日重复训练、单项和休息日训练不增加周完成天数，未来日期不算失败，跨午夜按整次训练创建日归属。

趋势按动作、目标、患侧、前臂长度、计划版本、训练类型及算法版本分组。部分结果单独展示，正常训练使用总合格/总完成次数汇总，完成为零显示暂无判定。实际训练用时与动作累计时长分别展示。

## 教学与离线

教学视频、封面、字幕按服务/动作/版本缓存，校验长度与 SHA-256 后整体切换，失败保留旧版完整内容。字幕可开关，为教学引导而非原音轨逐字转写。退出登录保留公共教学，卸载或清理 App 数据会删除缓存。离线模式只开放公共教学，无患者资料和训练。

工作人员可审核指定教学版本，更新内容后旧审核不自动沿用。需要重启后端生成新内容版本。

## 当前能力边界

人工复核、App 备份恢复、审计日志、报告导出及工作人员备注保存仍未接入；对应页面明确提示并禁用提交。机器人 SDK 示例、导航/充电及示例入口已移除。康复摄像头识别仍由后端完成。

模型/教学许可、真实动作准确性和 Jetson 性能尚需确认；算法反馈不代表临床评分。后端接口、SMTP、备份与部署以服务端 docs/api.md 和 docs/deployment.md 为准。
