# App使用说明

更新日期：2026-11-09。客户端操作以本文件为准；详细工程规则由后端主题文档维护，后续功能统一见 [开发清单](../../yolo26-pose-detection/docs/remaining_work.md)（同级工作区）。

## 连接与登录

登录页“连接服务”保存主机局域网地址，模拟器访问本机通常为 http://10.0.2.2:8000。服务端 /health 应显示 auth_required=true、data_schema=4。模型未就绪可登录和管理业务，不能开始识别。

客户端 1.3.0 按模式检查服务能力：本地骨架需 `local_skeleton_v1`，远端标注需 `annotated_video_v1`，诊断需原图诊断能力。缺少能力时提示升级或联系工作人员更改设置，不自动切换模式。

默认患者账号密码登录，下方管理员入口登录工作人员；初始工作人员账号 admin / 123。工作人员创建档案，核对患侧和前臂长度后分配患者账号。账号为 3–32 位字母、数字、下划线、点或短横线，统一小写且唯一；密码为 8–128 字符，已有账号留空可保留原密码，不能查看原密码。账号修改会撤销旧登录，训练中不能修改。

患者可不绑定邮箱；邮箱用于验证码登录和密码找回，由工作人员绑定且全局唯一。找回时输入账号、绑定邮箱、验证码和两次新密码。验证码五分钟有效、六十秒发送间隔、最多五次尝试且单次使用；找回和登录验证码独立。无邮箱或无法收信联系工作人员，工作人员账号不走患者找回。SMTP 需在后端配置，无固定验证码入口。

患者仅访问本人资料、计划和记录，不能修改档案、计划或教学审核。令牌本地使用系统 Keystore 加密，患者二十四小时、工作人员八小时。退出、到期或切换服务后重新登录。

## 计划与训练

工作人员设置 1–6 个不重复动作及目标次数、顺序、每周训练日和生效日期。首次计划可当天生效，已有计划调整最早次日生效；唯一待生效版本可替换，历史版本保留。患者单项练习仅允许当前计划内动作与目标，六动作教学均可观看。

计划/单项 → 整次前测 → 入镜准备 → 倒计时 → 训练/项间休息 → 整次后测 → 汇总。

多项目计划的项间休息页显示计划进度、30 秒倒计时和下一动作预览。“+20 秒”增加休息时间，“跳过休息”进入下一项准备；到零后仍需确认，不自动开始识别。点下一动作卡片可查看示范与步骤，返回后保留剩余休息时间；结束计划前需确认，已保存记录会保留。
准备阶段仅本地预览，不提前计数。工作人员在“设置 → 设备与服务”选择本机日常模式，默认本地骨架；退出登录保留，患者同样使用。进入训练时固定选择，计划内各动作沿用，下次进入才读取修改。

- 本地骨架：训练默认叠加人体与手点，可切换本地／骨架；连续 300 ms 无可用更新即隐藏。没有回传视频。
- 远端标注：等待首帧时显示本地并提示，就绪后自动显示服务端标注；可切换本地／远端标注，不绘制本地骨架。连续 3 秒无新远端帧后由周期检查回到本地并提示，恢复后手动切回。

切换只改变显示，不重连、不清零、不停止识别。远端标注切到本地后仍继续回传和解码；要减少开销，下一次训练选择本地骨架。达到目标只提醒，需手动结束。训练横屏，其他页面支持横竖屏；编辑档案和计划时固定方向保护表单。

握拳伸展当前标准（1.0.0-restored）：双手均须入镜，双手张开→握拳→再张开，无端点保持要求，合格周期0.7–3秒；保留原角度或手形兜底判定。训练页显示完成总次数、合格次数、不合格次数三项；总次数仅为合格＋不合格，目标进度和趋势仍用合格次数。中途缺手、无效几何、超时未完成和中途结束为无法判定，不混入三项统计或合格率分母，原结果数据保留。旧记录仍按原完成次数显示。教学视频暂为姿势示意，节奏以文字要求为准。

握拳提示按阶段与趋势引导“轻轻握起、慢慢松开、舒适可控”。幅度有限只给温和文字，持续明显偏差才允许语音，一次只播一条；不同原因冷却5秒、同一原因12秒，恢复后不补播旧纠正，静音/结束/退出即停播。当前未按患者个体ROM评分，不能把提示解释成肌张力或疲劳诊断。阈值与文字库统一见后端 [动作规则与患者提示](../../yolo26-pose-detection/docs/action_rules.md)。

无中文系统TTS的机器人使用9段内置普通话音频，Tingting语速180；系统TTS速率1.0。左右按实际人体侧称呼。动态手指提示主要保留屏幕显示，不强求统一终点。尚未实现患者个体活动范围评分、拇指/肩躯干代偿自动提醒；疼痛、肌张力、辅助施力不能由摄像头角度可靠诊断。实际音色、音量和提醒频率需现场确认。

机器人屏幕俯仰在 App 冷启动时默认发送档位 **10**；同一次运行中切换页面、切回前台不会重复调整。训练准备和训练中，点右上角“屏幕角度”用滑动条选择 **0–30** 的整数档位，再点“应用角度”。拖动只预览数值，关闭弹窗不会移动。选择只在本次运行中保留，下次冷启动恢复 10。调整时暂缓动作，完成后确认手部重新入镜；调节不会重建识别连接或清零次数。失败时入口显示“重试”，不会自动重复发送；先观察实际位置再决定是否重试。

0–30 是本次指定的 App 调节范围，不代表厂家确认的机械限位；界面数值不标为“度”，服务确认也不代表传感器实测到位。非机器人设备上，本机角度服务不可用时仍可使用其他 App 功能。接口与开发测试见 [screen-angle-test.md](screen-angle-test.md)。

训练准备、开始倒计时和动作训练使用全屏摄像头，信息以深色半透明浮层显示。左上动作/患者信息框随内容收窄；左侧次数居中，合格/不合格数字加大，FPS 与统计框同宽对齐。上方中央显示入镜或动作提示，右侧显示目标进度，底部保留画面切换、语音、入镜要求和结束操作。倒计时暂时隐藏统计与操作，结束后恢复。达到目标和片段记录状态仍单独显示；“因不适结束”旁保留保存部分结果、结束整次训练的后果。分段条仍按原目标规则计算。

摄像头画面等比例居中裁切铺满屏幕，可能裁掉原图上下或左右边缘；请以屏幕实际可见范围核对入镜。采集与识别尺寸不变，本地骨架使用相同裁切和镜像映射；诊断副屏仍完整适配原画面。大字号或窄屏时底部操作分两行，低高度时次数区可滚动。

采集继续请求 640×480、15 FPS，实际出帧率由设备决定。本地视频不等待识别结果，快速动作时骨架可能短暂落后；网络 RTT 不等于完整画面延迟。

疼痛/疲劳 0–10 分，默认未填；零分、未填和跳过分开保存。后测增加困难程度，不适说明可选填。实际开始后不能改前测，动作之间不重复问卷。

“因不适结束”保存部分结果、结束整次训练并提供可跳过后测，不计作计划完成。切后台、断线和令牌失效按不同原因中断，不续接旧计数。结果先保存在服务端，丢失响应按会话 ID 查询；后测失败可稍后补填，不覆盖训练结果。

## 设备诊断

设置页已移除“下一次训练开启远端诊断”，旧开关在进入 App 主界面时清除。正常训练沿用所选的本地骨架或远端标注模式。远端原图仅供显式性能测试使用，不在患者日常流程中开放。

训练页 FPS 的诊断数据仍可用于排查连接问题。“解码→绘制”为服务端解码出帧到 Android 骨架绘制的估计耗时，不包括采集和上传；完整画面延迟需外部拍摄测量。

## 日程与记录

按北京时间计算计划日；应训练日全部动作正常结束记一天完成，目标是否达到另列。同日重复训练、单项和休息日训练不增加周完成天数，未来日期不算失败，跨午夜按整次训练创建日归属。

趋势按动作、目标、患侧、前臂长度、计划版本、训练类型及算法版本分组。部分结果单独展示，正常训练使用总合格/总已判定次数汇总（旧规则为原完成次数），已判定为零显示暂无判定。实际训练用时与动作累计时长分别展示。

## 人工复核与康复训练单

工作人员从“人工复核”“康复训练单”菜单或训练详情对应入口进入。App 内保留左侧菜单和顶部栏，直接沿用当前工作人员登录，无需再次登录网页。可用“返回”、系统返回或菜单切换离开；有未保存输入时先确认，切后台再回来保留当前填写内容，填写时固定屏幕方向。沿用现有深绿/浅底/白卡风格；“人工复核”独立展示错误事件、片段和逐条结论，“康复训练单”独立填写《康复训练情况记录表》。宽屏原生菜单中训练单位于人工复核下方，窄屏使用嵌入页顶部切换。两栏目切换保留所选训练及未保存输入，转到训练单时暂停视频。可复制网页地址，在电脑 `/review/` 用同一工作人员账号登录；网页页头与App分别展示，嵌入页不重复显示网页标题；页面精简副标题和说明，保留操作标签及必要状态。

握拳准备页可勾选“保存不合格片段（无录音）”，每项默认关闭，只保存已结算不合格动作及前后各2秒；无法判定单列，无视频/旧记录不补造。编码失败、缓冲不完整和空间已满会显示状态，原计数保留。视频10FPS、640×480以内，单窗口20秒、视频与封面合计单片8 MiB、目录共用1 GiB，重叠窗口合并。

每条结论选“确认需要调整”“动作可接受 / 算法误判”“证据不足”并填判断依据。训练单基本信息全部由康复师手填，不从档案自动填入；顶部显示关联患者供核对。可保存草稿，关键字段完整且所有事件复核后确认完成；完成后锁定，进入修订保留旧版。未保存退出有提示，同时编辑发生冲突时保留输入供核对。复核不改原始统计，摄像头不能诊断疼痛或肌张力。

片段仅工作人员可播放/删除；删除保留事件、结论和训练单，共用片段的事件同时失去回放。电脑可打印已保存训练单和片段结论。视频保存在后端，审核完成不会自动删除或释放空间。容量满时新片段不可用，原训练统计继续保留；目前没有存储看板和按保留期自动归档/清理。媒体目录须与数据库配套备份，单独数据库备份不包含视频；完整存储说明见后端 [人工复核与视频存储](../../yolo26-pose-detection/docs/therapist_review.md)。

## 教学与离线

教学视频、封面、字幕按服务/动作/版本缓存，校验长度与 SHA-256 后整体切换，失败保留旧版完整内容。字幕可开关，为教学引导而非原音轨逐字转写。退出登录保留公共教学，卸载或清理 App 数据会删除缓存。离线模式只开放公共教学，无患者资料和训练。

工作人员可审核指定教学版本，更新内容后旧审核不自动沿用。需要重启后端生成新内容版本。

## 当前能力边界

人工复核与康复训练单已接入，网页支持已保存版本打印；App备份恢复、独立审计查询、批量报告导出和工作人员其他备注保存仍未接入，对应页面明确提示并禁用提交。机器人 SDK 示例、导航/充电及示例入口已移除。康复摄像头识别仍由后端完成。

模型/教学许可、真实动作准确性和 Jetson 性能尚需确认；算法反馈不代表临床评分。后端接口、SMTP、备份与部署以服务端 docs/api.md 和 docs/deployment.md 为准。

界面沿用绿色主题，主页面不再常驻展示患者编号，编号仍用于患者选择与档案核对。登录、首页、计划、记录和设置去掉重复副标题与口号；保留标签、加载/错误/保存状态和安全提示。宽屏训练记录的六列表头放大并居中，与数据列对齐；复核结论的保存状态与按钮保留 16px 间距。
